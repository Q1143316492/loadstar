01你打字的时候，消息先进两个队列

不是直接给模型看。因为你不希望每说一句就把正在干活的 agent 打断。

next-step「停一下，改成 X」
next-step「还有这个」
next-turn「下一轮再看这个」

两种语气：next-step = 当前这一步结束立刻带上；next-turn = 这一整轮跑完、下一轮开头才取。

代码里：steer()/inject() 推 step；followup()/enqueue() 推 turn。

03差别是这一行

真的只有一行。

def claim(self, target):
    claimed = list(self._next_step)
    self._next_step.clear()
    if target == "next-turn" and self._next_turn:
        claimed.append(self._next_turn.pop(0))
    return claimed
def claim(self, target):
    claimed = list(self._next_step)
    self._next_step.clear()
    if target == "next-turn" and self._next_turn:
        claimed.append(self._next_turn.pop(0))
        return [self._next_turn.pop(0)]
    return claimed
    return []

右边把「倒空 step」和「把 step 的内容带出去」拆开了：队列清了，内容没人接。这是真实会发生的一类重构事故。

04TLA+ 找的就是这个

规则一句话：推入的每条消息，要么还在队列里，要么被取走了。

第 1 步
PushTurn(0)
nextTurn = <<0>> · nextStep = <<>> · claimed = {} · pushed = {0}
第 2 步
PushStep(1)
nextTurn = <<0>> · nextStep = <<1>> · claimed = {} · pushed = {0, 1}
第 3 步
ClaimTurn
nextTurn = <<>> · nextStep = <<>> · claimed = {0} · pushed = {0, 1}

1 被推进来过，现在既不在队列里也不在已认领里 —— NoLoss 违反

TLC 的完整输出：

Error: Invariant NoLoss is violated. · 退出码 12 · 63 个状态里找到的最短路径就是这三步。

为什么普通测试不容易抓到：要写测试，你得先想到「step 在 turn 之前推入、然后一次 claim」这个组合。这个 bug 只在特定顺序下出现。63 个状态里，人不会挨个试。

def test_claim_does_not_lose_step_messages():
    ib = Inbox()
    ib.push_turn(msg("A 下一轮"))
    ib.push_step(msg("B 立刻"))

    got = ib.claim("next-turn")

    # 推入 2 条，就必须认领到 2 条
    assert len(got) == 2
    assert "B 立刻" in [m.content[0].text for m in got]

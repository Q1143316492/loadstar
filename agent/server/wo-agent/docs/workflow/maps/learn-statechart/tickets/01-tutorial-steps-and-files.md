## 问题

`docs/learn-statechart/` 下应该有几个文件、每个文件对应哪一步、每步的产物是什么？

要钉住的约束：

- 一步一个文档，但「一步」的粒度未定——是按概念分（状态模型 / 不变量 / 穷举 / 反例回放），还是按验收分（跑通 TLC / 看见它失败 / 回放成测试）。
- 每一步必须能独立读完就动手，不要求先读完别的步骤。
- 目的地要求的三条验收必须能被某一步明确认领，不能散在几篇里。

答案产出：一张「文件名 → 这一步要你做什么 → 产物是什么 → 它认领哪条验收」的表。

类型：grilling
状态：已解决
阻塞于：无

## 答案

**切法：按验收切，不按概念切。** 每篇文档都以「跑出一个结果」结尾；概念只在卡住时按需链接，不前置讲解。

**代码给到骨架级**：事件类型、随机序列生成、pytest 外壳给全；不变量与规格的 `Init`/`Next` 留空并标注「写完应该看到什么」。

**理论外链**：每篇不讲课，只链 `lodestar/docs/learn-pstack/statechart.md` 与 `statechart.html`。概念在亲手撞过一次之后再读才有意义。

**验收标注**：每篇末尾一行「这一步认领：验收 N」，`README.md` 里放总表。

**阶段边界（Phase boundaries）**

**阶段（phase）** 是一个会话内部的一块工作：访谈、实现、QA。这个定义故意是模糊的：当你想*「好，这块完事了」*的时候，一个阶段就结束了。

**阶段边界（phase boundary）** 是两个阶段之间的空隙，这个决策只属于那里。阶段中途没有什么可决定的：继续，或者把剩下的工作拆给 subagent。在阶段中途 compact 会让 agent 丢掉线索。

### 2.1 五个选项（The five options）

| 选项          | 它做什么                                                       |
| ------------- | -------------------------------------------------------------- |
| **Continue**  | 留在会话里。完全不切换上下文。                                  |
| **`/clear`**  | 清空上下文窗口，从零开始。                                      |
| **`/handoff`** | 写一个可携带的 markdown 文件，用它到任何地方给一个会话播种。     |
| **Subagent**  | 把任务送到它自己的上下文窗口，拿回一份报告。                     |
| **`/compact`** | 压缩这段上下文，用这份摘要给一个全新会话播种。                   |

### 2.2 决策树（The tree）

在边界处从上往下走。第一个**是**胜出。

**1. 你能在这个会话里继续吗？** 两件事会让答案是「是」：下一个阶段需要这个阶段作为**一手来源（primary source）**，或者你剩下的 [smart zone](https://www.aihero.dev/ai-coding-dictionary/smart-zone)（约 150k tokens）足够装下下一个阶段。访谈 → 实现是标准的「是」：实现想要的是推理的原话，而不是它的摘要。Continue 不花费什么、也不丢失什么，所以要先于其他一切把它排除掉。

**2. 这段上下文与接下来要做的事无关吗？** 这个会话里的一切（探索、决策、死路）都可以丢弃吗？如果是，**`/clear`**。它是棋盘上最便宜的一步：不花时间，还把整个窗口交还给你。`/clear` 也不是终局：旧会话仍然可以恢复。

搞错这件事的代价是单向的。清掉一段*相关*的上下文，你就丢掉了你所构建之物背后的**为什么**，而再怎么看 diff 也换不回来。

**3. 你需要交接吗？** `/handoff` 范围很窄。只有当你处于以下情况时才需要它：

- 换到一个**新 harness**（Claude → Codex），
- 搬到一个**新目录**或新仓库，
- 把工作交给一位**同事**，
- 或者分叉一个你在**阶段中途**发现的支线任务，同时不偏离你正在做的事。

那份清单就是全部条款。`/handoff` 买到的是**可携带性**：一个会旅行的文件。如果没有东西在旅行，你就不需要它。

**4. 这个任务能在你离开键盘时完成吗（AFK）？** 它的范围收得足够紧，可以在你离开键盘、不做任何操控的情况下跑完吗？那就把它送给一个 **subagent**，让这个会话保持原封不动。自动化评审是标准情形：agent 读 diff 并汇报，它做这件事的时候不需要你。

**5. 否则，`/compact`。** 相关的上下文、同一个 harness、同一个目录，而你又需要留在回路里：这就是决策树落地的地方，而且它经常落在这里。给它传一条指令（`/compact we're going to QA this area`），好让摘要保留下一个阶段需要的东西。

`/compact` 是**默认项，不是第一手就抓的东西**。它坐在底部，因为它上面的四个问题都更便宜或更精确。人们从这里起步时的失败模式，是得到一个全新会话，它对某个被摘要压平了的决策自信地判断错误。

### 2.3 一手来源与二手来源（Primary and secondary sources）

除了 **Continue** 之外的每一步，都会把一份**一手来源（primary source）** 变成**二手来源（secondary source）**：一个如实发生的会话，被它的摘要取代。这笔交易形状始终一样：

| 来源                               | 信息 | 噪音 | 可腾挪的空间 |
| ---------------------------------- | ---- | ---- | ------------ |
| 一手（Continue）                    | 全量 | 很多 | 很少         |
| 二手（`/compact`、`/handoff`）      | 有损 | 更少 | 很多         |

这就是问题 1 排在第一位的原因。只有当留下的代价高于它省下的，你才需要为有损性买单。

### 2.4 这些都是判断题（These are judgement calls）

这些问题不是客观的：每一个里面都有品味，同一个边界在两天里可以走向两种结果。价值在于**按顺序**问它们，在边界处问，而不是在工作中间问。

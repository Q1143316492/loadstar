**frontmatter**

- `name`: `research`
- `description`: `Investigate a question against high-trust primary sources and capture the findings as a Markdown file in the repo. Use when the user wants a topic researched, docs or API facts gathered, or reading legwork delegated to a background agent.`（针对高可信度的一手来源调查一个问题，并把发现作为一份 Markdown 文件捕获到仓库里。在用户想要研究一个主题、收集文档或 API 事实，或把阅读跑腿委派给一个后台 agent 时使用。）

拉起一个**后台 agent** 来做研究，这样它阅读时你可以继续工作。

它的工作：

1. 针对**一手来源（`primary sources`）**（官方文档、源代码、规范、第一方 API）调查这个问题，而不是针对它们的二手转述。把每一条主张都追溯回拥有它的那个来源。
2. 把发现写进一个 Markdown 文件，为每一条主张标注来源。
3. 把它保存在仓库已经存放这类笔记的地方；沿用已有约定，如果没有约定，就放在一个合理的位置并说明在哪里。

## 目的地

把「逐行读一个陌生开源库」变成一套可靠的读法，并在 `pi-mono` 的 `packages/agent` 上首轮跑通三拍：**浅入口**（模板化的目录 / 架构地图，深度有上限）→ **陪读**（读到哪、讲到哪；讲机制、串脉络）→ **块末出图**（图随读累积成册）。验收以**你自感理解**为准；跑通后决定要不要结晶成 `cwl-` 技能。

## 备注

- 领域：AI agent 内核源码；试点库 `badlogic/pi-mono` → `packages/agent`（TypeScript）。
- 每个会话先看：`cwl-prototype`（出样例给人反应）、`cwl-research`（查一手事实）；拿不准时 `cwl-grilling` + `cwl-domain-modeling`。
- 固定偏好：
  - 验收 = 你自感理解，不设教回关卡；哪块没底随时喊深挖。
  - 陪读是**拉取式**：读到哪、花到哪；唯一刻意做浅的是入口地图（深度有上限，避免全量分析开销）。
  - 「AI 主导 + 全库理解文档」是死路：五代已否，见 `docs/attempts/01-codeview.md`；不要再产出这类产物。
  - 阅读靶子（暂定，可随时改）：agent 包的**设计思路**——核心循环怎么组织、工具与上下文怎么管；主线深读、其余略过。
- 最初需求只报过第 1 条（陌生库理解）；2、3 若想起直接补。
- lodestar 库本体的其他迭代（与读库无关）不在本图。

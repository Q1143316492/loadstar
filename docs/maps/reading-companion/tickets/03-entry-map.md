# 入口地图规格与样例

## 问题

定「入口地图」的规格并出样例：读之前先给你一份**刻意浅**的模板化产物——目录结构 + 顶层架构 + 推荐阅读主线（先读哪、为什么、什么可跳）；深度上限明确，避免全量分析的开销。

要定：模板节数与每节深度上限、格式（图怎么画、怎么排）、产物落哪（目标库仓内？独立伴读目录？）、要不要复用 01 留下的可用件（锚点格式 `相对路径#符号名`、逐项表态「未展开（原因）」，见 `docs/attempts/01-codeview.md` §3.3）。

样例在 `packages/agent` 上实跑一份给你看；规格以「你看一眼能不能用」为准。

参考：[`../research/module-viewers.md`](../research/module-viewers.md)（Uncle Bob 的 `uml-viewer` / `arch-view`：分层矩形 + 入/出边三角 + 下钻、深度上限的画法）。

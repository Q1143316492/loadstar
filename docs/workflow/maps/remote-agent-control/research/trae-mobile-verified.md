## 2. 官方文档事实

文档页：<https://docs.trae.cn/work_get-started-with-trae-mobile>（《快速开始：TRAE 移动端》，页面记录 `updated_at` 2026-10-09）

原文要点：

- **下载**：「前往你手机的应用商店，搜索 "TRAE" 应用并下载。」并注明「"TRAE" 应用目前尚未在美区 App Store 上架」，建议换其他地区 Apple ID 尝试。
- **定位**：「TRAE 移动端的核心定位是**跨设备的任务下发中心**。它采用操作界面与任务执行分离的架构，支持向云端沙箱及已配对的个人电脑下发任务。」
- **连接电脑的完整步骤**：
  1. 手机打开 TRAE 移动端，**手机号登录**
  2. 首页左下角点「任务运行环境」→ **连接我的电脑**
  3. 电脑打开 **TraeWork 桌面版**，用**同一手机号**登录
  4. 桌面端「设置 > TRAE 移动端」→ 打开「**允许 TRAE 移动端控制当前设备**」
  5. 确认「仅必要内容会存储在云端」弹窗（原文：「仅你的对话内容和 AI 生成的产物（如文档、代码变更等）会存储在云端」）
  6. 授权移动端访问电脑中的 **`/documents` 目录**
  7. 可选「保持电脑处于唤醒状态」
- **连接有效期 180 天**，到期需重连。
- **两种模式 × 两个执行地**：
  - Work 模式：云端直接发；电脑需先选一个存放产物的文件夹
  - Code 模式：云端需先选代码仓库与分支（需授权 GitHub）；电脑同样选文件夹
- **技能是点选的**：「技能：选择在 TraeWork 桌面版和网页版中启用的技能」——不是打斜杠命令。
- **进度同步**：同账号下移动端 / 桌面版 / 网页版三端互相同步；但「网页版仅支持云端环境，因此不支持查看本地任务」。
- **产物预览**：支持文档、代码、Web 页面；**但**「TRAE 移动端仅支持预览由云端任务生成的 Web 页面。如需预览本地任务生成的 Web 页面，使用桌面版或网页版查看。」
- **后台/断网**：任务一旦下发便在目标环境独立执行，App 状态不影响；网络恢复后自动同步。
- **个人设置**：隐私模式、语言（英/简中/日）、通知（任务完成/中断/需介入）、设备管理、三方应用授权（目前仅 GitHub）。

另有独立的开源声明页，证明两端都存在：
- 《TRAE 移动端（安卓）开源软件声明》`work_open-source-software-notice-for-trae-solo-mobile-android`
- 《TRAE 移动端（iOS）开源软件声明》`work_open-source-software-notice-for-trae-solo-mobile-ios`

## 3. 修正与未证实项

**「手机端有 Unified Diff View」——只有 App Store 文案这一个来源。**

- App Store 描述原文：「产物预览与文件管理：AI 生成的代码、文档、图表等产物可直接在手机端预览，**支持 Unified Diff View 查看代码变更**，随时掌握交付结果。」
- 但官方文档《快速开始：TRAE 移动端》**通篇没有出现 diff / 变更视图**，只写到「支持预览智能体生成的产物，包括文档、代码、Web 页面等」，且没有任何界面截图涉及 diff。
- 结论：**厂商在商店页声称、文档未展开、无截图佐证**。按「未证实」处理，不能当成已验证能力。

**TRAE 与字节的关系：未核实。**

- App Store 发行方是「北京引力弹弓科技有限公司」；`trae.cn` 的备案/执照页出现的是「北京春田知韵科技有限公司」。两个都不是「字节跳动」字号。
- `trae.cn` 首页内嵌数据里只有一个 `"enterpriseChannel":"volcano"` 字段（火山引擎属字节系），不足以作为归属证据。
- 本轮**未查到**权威一手说明，先前材料里的「（字节）」标签应删除。

**产品线更名**：文档「重磅更新：TraeWork 已升级为全新的 TRAE」条目，正文与菜单使用 **TraeWork 桌面版 / 网页版**、**TRAE 移动端**。旧称 TraeCode / TraeWork 已融合。

## 4. 对下游决策最关键的事实

1. App 真实存在（中国区 App Store，id 6761400733），iOS + 安卓双端，免费。
2. 连接方式走厂商中继：手机号配对，桌面端一键开关，**不需要公网 IP、不需要穿透**。
3. **有效期 180 天**、**授权范围是 `/documents` 目录**——两点都要在评估时算进去。
4. **技能是点选的**，正面命中「记不住斜杠命令」的痛点。
5. diff 视图**只有商店文案**，文档无对应说明——评估时必须自己装上验证。
6. 本地任务的 Web 页面预览在手机上不可用，必须回桌面端或网页版。

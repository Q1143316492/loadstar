# 国内能用的远程控制链路有哪些

## 问题

查清国内环境下「从手机控制一台 PC」的可选链路：商业远控（UU远程、向日葵、ToDesk）、开源（RustDesk 等）、以及不用穿透的替代路径。重点是各家的真实门槛（月费、被控端要求、手机端体验）与「拿来看代码」的实际限制，要有可引用来源，不是罗列产品名。

状态：已解决

## 答案

2026-11-26 由调研子智能体解决，事实清单在 research 文件里（含价格、端口、逐条来源与「未查到」清单）。对下游有用的要点：

- **商业远控三家的共同门槛极低**：被控 Windows 需装客户端，但**不需要公网 IP，厂商服务器中转，用户侧零配置**——这正好命中「不想配穿透」。UU 远程当前「基础远控免费、不限次不限时」，官方 2026-11-19 公告承诺 12-01 上线 VIP 后基础功能继续免费；向日葵、ToDesk 免费档明写 1080P/30 帧。
- **UU 远程值得单独看**：官网功能页列了「端口映射」「终端连接（远程开发场景）」「远程 AI Coding」，文件传输不限大小、多屏控制、远程开机。也就是说它不只是一块屏幕。
- **自家打洞/自建中继全线要公网服务器**：RustDesk 自建要 21115–21117 端口；Headscale 要 80/443 + 3478；frp 同样。绕不开「租一台有公网 IP 的机器」。
- **Tailscale / ZeroTier 在国内不成立**：大陆无 DERP 节点、iOS 版在中国区 App Store 已下架、有运营商线路干扰控制面的案例。用户否决配穿透是对的。
- **最省事的绕开路径**：agent 跑云主机，手机 SSH 或浏览器终端接入。腾讯云轻量最低 2 核 2G/3MB/200GB 为 ￥45 月，与新锐驰型同价。
- **手机控整个桌面的真正痛点是输入映射**（触控板模式 vs 直接触摸、滚轮方向、修饰键），不是带宽；软键盘是否遮挡输出没有任何可引用实测。

采集局限：本机 WebFetch/WebSearch 被网络门禁拦截，调研走 curl + Bing CN/搜狗，个别项（阿里云轻量月价、剪贴板同步、微信远程协助）未查到，文件里已逐条标注。

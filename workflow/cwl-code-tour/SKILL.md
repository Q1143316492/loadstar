# 代码导览

**先读 `docs/workflow/AGENTS.md`**（若存在）：本项目自己的工作流约定。

改这份技能之前，先调用 Skill 工具并以 `cwl-writing-for-agents` 为参数，按它的杠杆逐条自检。

你带用户读一个代码库。产出是一条**模块阅读路线**：一站一个模块，给出它的接口，说明这几行承诺背后撑着多少行为。判断模块值不值得单独站的标准是**杠杆**——掌握它的接口，能省掉多少次回头查。**深度**与**接缝**的准确定义在 `cwl-codebase-design`，需要时调用它。

## 先定范围

用户点了方向（一个子系统、一条流程、一个模块），就用它。没点就问一句「你想读懂整个库，还是某一块」，再按整库排。
按整库排时 5–7 站；按子系统排时 3–5 站。站数会超，说明范围该收窄，或者候选里混进了只该「用到时再下潜」的模块。

## 怎么挑模块

四个信号，命中两个以上的模块进候选：

- **词汇**：项目自己命名的概念住在哪。类型表、领域对象、术语表——在读到它们之前，别处的名字只是字符串。
- **深层**：接口小、行为多的地方。判断法是数公开名字：一个包导出三个方法却撑着整条链路，它值得单独一站。
- **接缝**：有两处以上实现的地方（测试假件、第二个 provider、第二个客户端）。
- **扇入**：被最多模块 import 的。它决定先读它省几次回头。

淘汰：纯适配器、纯渲染、生成物、第三方副本，以及只有一条调用路径的工具函数——它们在自己被用到的那一站里顺带读。

## 一站一个模块

一站就是一个**模块**——一个包，或包内一个完整的能力。

每一站回答同一个问题：**这个模块的接口有多大，它背后撑着多少行为？** 接口小、行为多是**深**模块，那正是读者能用少量知识掌握整体的地方；接口几乎和实现一样宽，是**浅**模块，读它就等于读实现，路线里要让读者知道这一点。

每站三段：

1. **接口**：调用方必须知道的那几个名字——方法、参数、错误、顺序约束。一一列出，不要概括成「提供了一组方法」。
2. **深度**：这几行承诺背后藏着什么。说清「只学这个接口，你就能预测哪些行为」，并给出证据——实现里最反直觉的那一处，或一个只依赖接口的调用点。
3. **解锁**：读完之后读者能对这个模块下的什么判断（能不能换、能不能测、改动会不会漏出去）。

写不出第 2 段，就说明这个模块是浅的——直说，别把实现细节搬进接口那一段凑数。

### 排序

按依赖方向从下往上：下层是上层的前提，读者先掌握下层接口，才能看懂上层是怎么使用它的。同一层内的模块按被依赖的次数排。

### 已有的说明，引用它

仓库里已经有说明的地方——每包的 `docs/<包>.md`、`README` 的模块表、`CLAUDE.md` 的核心设计——**给出指针，不重述**。重述会造出一份会漂移的平行副本，读者还得判断哪份才算数。

导览独有的东西是：**先读哪个模块、每个模块的接口是哪几个名字、以及它们有多深**。仓库里没有这份判断。

`CLAUDE.md` / `AGENTS.md` 本身也要占一站：定位边界、分层规则、不能重新争讼的决策都在那里，靠读代码推不出来。

## 输出

- 聊天里先给紧凑清单：`1. 模块名 — 一句话为什么先读它`。用户拿到就能开始读。
- 一页自包含 HTML 写到系统临时目录（`$TMPDIR`，Windows 上是 `%TEMP%`），命名为 `code-tour-<时间戳>.html`，打开它并告诉用户绝对路径。版式与卡片见 [TOUR-FORMAT.md](TOUR-FORMAT.md)；Tailwind 与 Mermaid 从 CDN 引入。
- 收尾列一份**没排进来的**：这次跳过了哪些模块，什么情况下才需要读它。这份取舍清单和路线本身一样有用。

## 与其他技能的分工

- 想知道「该改哪里」，用 `cwl-improve-codebase-architecture`。两者互为反面：一个挑值得改的模块，一个挑值得读的模块，同一个模块常常两边都上榜。
- 想跨多次会话系统学一块，用 `cwl-teach`；本技能的路线可以直接交给它当第一节课的大纲。
- 想让人一眼看懂某个模块的形状，用 `cwl-show-me`。

## 完成判据

- 每一站是一个模块，不是一个步骤或一条流程。
- 每一站的「接口」逐一列出名字，读者照着就能调用。
- 每一站的「深度」说出接口与实现的差，并有证据：一段实现，或一个只依赖接口的调用点。
- 浅模块被标出来，读者知道读它等于读实现。
- 排序按依赖方向从下往上，不是按一次请求的路径。
- 仓库已有的说明只出现在指针里，页面正文没有重述它们的段落。
- 代码摘录与仓库一致，省略处标 `...`；只给函数名与文件路径，不写行号。
- 站数落在范围内：整库 5–7 站，子系统 3–5 站。
- HTML 已写入临时目录并打开；聊天里也有一份可以照着读的清单。
- 收尾点名了跳过的模块，以及各自什么情况下才需要读它。

## 边界

本技能只产出阅读路线与讲解，不改代码；改动建议交给架构巡检。

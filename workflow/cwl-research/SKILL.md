description: "针对高可信度的一手来源调查一个问题，把发现写成仓库里的一份 Markdown 文件。当用户想研究某个主题、收集文档或 API 事实，或想把阅读的跑腿活交给后台代理时使用。"
---

拉起一个**后台子智能体**去做调查，这样它读它的，你继续干你的。

它的活：

1. 对着**一手来源**（官方文档、源码、规范、第一方 API）调查这个问题，而不是它们的二手转述。每一个论断都要追到拥有它的那个源头。
2. 把发现写成单独一份 Markdown 文件，每个论断都注明来源。
3. 存到仓库已有同类笔记的地方；匹配现有惯例，没有惯例就放个合理的位置并说明放在哪。

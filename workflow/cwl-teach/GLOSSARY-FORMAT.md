# GLOSSARY.md 格式

`GLOSSARY.md` 是这个教学工作区的规范语言。所有讲解、练习、学习记录都应当遵守它的术语。建它本身就是学习的一部分：把一个概念压成紧凑的定义，就是理解它的证据。

## 结构

```md
# {主题} 词汇表

{一两句话说明这份词汇表覆盖的主题。}

## 术语

**肌肥大**：
反复训练下由机械张力与代谢压力驱动的肌肉增长。
_避免_：增肌期、练壮

**渐进超负荷**：
随时间系统地提高对肌肉的要求：加负荷、加量、或加强度。
_避免_：练狠一点、升级

**RPE（自觉用力程度）**：
对一组动作有多费劲的 1–10 自评，10 是力竭，8 表示还剩两次。
_避免_：用力分、强度评分
```

## 规则

- **只在用户懂了之后才收词。** 词汇表是压缩知识的记录，不是让用户读着学的字典。刚介绍过某个概念，等他能正确使用了再收进来。
- **要有主见。** 同一个概念有好几个词时，挑最好的一个，其余列为要避免的别名。语言就是这样压缩的。
- **定义要紧凑。** 一两句话。定义这个术语*是*什么，而不是它*做*什么、怎么做。
- **定义里用词汇表自己的术语。** 一个术语进了词汇表，就到处优先用它，包括在别的定义里。这正是让复杂术语日后更容易掌握的原因。
- **自然聚类出现时，归到子标题下**（例如 `## 解剖`、`## 训练编排`）。术语彼此内聚时，平铺列表就可以。
- **显式标出含糊处。** 某个词在领域里被用得很宽松，就写下这里的约定：「在这个工作区，『组』一律指正式组；热身单独记。」
- **随理解加深而修订。** 第一周写下的定义，到第六周可能已经错了。就地更新，不要留着过期条目。

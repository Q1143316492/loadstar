# RESOURCES.md 格式

`RESOURCES.md` 是这个主题的可信来源清单。课程里的知识应当从这里取，而不是从参数化猜测里来。智慧来自这里列出的社区。

## 结构

```md
# {主题} 资源

## 知识

- [书：《力量训练的科学与实践》，Zatsiorsky & Kraemer](https://example.com)
  关于训练编排与适应的基础教材。用途：周期化、恢复、强度区间的任何问题。
- [文章：《我该练多少？》，Greg Nuckols（Stronger By Science）](https://example.com)
  关于训练量地标的循证综述。用途：每个肌群的每周组数目标。

## 智慧（社区）

- [r/weightroom](https://reddit.com/r/weightroom)
  信噪比高的 subreddit，有管理，挡掉了「健身房玄学」。用途：训练计划点评、平台期排障。
- 线下：{健身房名} 周二力量课
  用途：举重动作的实时指导反馈。
```

## 规则

- **只要高可信。** 优先一手来源、公认专家、同行评议的工作，以及管理严格的社区。把营销包装成教学的东西，不要写进来。
- **每条都要注释。** 光一条链接三个月后就没用了。加一行：它讲什么、什么时候该用它。
- **按知识 / 智慧分组。** 呼应 [SKILL.md](./SKILL.md) 里的理念。一个资源只出现在一组里也没问题。
- **把缺口写出来。** 使命需要的某个方面找不到好资源，就写一节 `## 缺口` 列出缺什么。它驱动之后的检索。
- **狠心修剪。** 事后发现是错的、浅的、或偏离使命的资源要删掉，而不是埋起来。五个锋利的来源胜过三十个平庸的。
- **记下社区偏好。** 用户说过不想加入社区，就记在这里，免得以后的会话反复推荐。
